# Normal Map To Mesh (法线 → 多级精度高模)

把切线空间法线贴图重建为 Multires(多级精度)修改器上的真实高模几何细节——
是真实位移，不是渲染时的光照近似。

## 用法

1. 选中目标网格(需有 UV)。`3D视图 > 侧栏(N) > Ruri > 法线 → 多级精度高模`。
2. **游戏资产**(材质里已有法线贴图节点链): 来源保持"自动", 直接点 **应用 / 更新**。
3. **裸网格 + 贴图文件**: 点 **加载法线并一键构建** 选文件(自动切到贴图模式)。
4. 求解器默认是 **UV Poisson（传统）**；想试真实拓扑上的重建，改成
   **位置 + 法线联合优化（实验）**。
5. 调 **高度倍数**(默认 1.0 = 物理高度)后再点应用——从基面重新算，不叠加。
6. **移除细节** 一键恢复低模。

联合模式的 PCG 在后台线程跑，状态栏显示进度，期间 Blender 可以继续操作，
按 `Esc` 取消(不会提前改写 Multires)。脚本/无界面调用仍是同步的，方便做可重复测试。

工作分辨率不用手动设置：它自动等于实际接入的法线贴图的原生分辨率(沿材质 Normal Map
节点的 Color 输入网络回溯，找到 Image Texture 的尺寸)。设高了只是把已有像素插值放大，
不产生新细节还更慢；设低了会丢掉贴图里已有的信息。两种都没好处，所以没做成选项。

## 原理

核心假设只有一条：**位移是光滑场作用在光滑曲面上，细分级别只是采样密度**。
一切量都由低模和贴图决定。基面各级顶点都落在同一张极限曲面上
(`use_limit_surface`，嵌套采样)；高度场是固定的物理场，每个级别只是它经过
与级别匹配的重建滤波后的光滑投影。可以拿平滑曲线类比：4 个控制点和 100 个控制点
表达的是同一条曲线，只是一个粗一个细，每一级都该是光滑的。反过来，如果某一级
看着"粗糙"，说明有离散量没被场化——那是实现上的问题，不是级别本身的性质。

### 两种重建后端

**UV Poisson（传统，默认）**先把法线坡度积分成图集高度场，再逐岛去趋势、缝合，
最后采样到细分网格。它保留 v6.2 的结果，适合对既有工程做可重复重建。

**位置 + 法线联合优化（v6.4 实验）**不把 UV 图集当成几何拓扑。它以细分极限曲面
作为位置先验，每个细分顶点只解一个沿光滑基面法线的标量位移 $`d_i`$。法线贴图给出的
$`\partial h/\partial u`$、$`\partial h/\partial v`$ 在每条面内边上构成一个位移差观测：

```math
\begin{aligned}
d_j-d_i &\approx g_e,\\
g_e &=
\frac{\partial h}{\partial u}\,\Delta u
+
\frac{\partial h}{\partial v}\,\Delta v .
\end{aligned}
```

```math
\min_{\mathbf d}\;
\sum_{e=(i,j)} w_e\,
\rho\!\left((d_j-d_i)-g_e\right)
+
\lambda\sum_i m_i\!\left(d_i-d_i^{(0)}\right)^2 .
```

$`\rho`$ 是 Huber 损失，IRLS 会自动降低 UV 缝两侧冲突、压缩噪声和孤立异常值的权重；
$`\lambda`$ 是"位置保持"，$`m_i`$ 用局部面积尺度抵消细分级别变化，$`d_i^{(0)}`$ 是基面位移
先验(当前为 0)。固定权重时这是一个带位置屏蔽项的加权图拉普拉斯，用纯 NumPy 的
矩阵自由 PCG 求解，不依赖 SciPy。UV 只用来查法线梯度：同一几何边在 UV 缝两侧可能
产生两条观测，但它们共享同一对几何顶点未知量，所以普通 UV 缝不再引入任意岛常量或
人为折痕；真实开放边界仍然硬锁在低模位置。

目前的联合模式是**沿法线方向的标量位移**，不是自由 XYZ 顶点优化。这样保留了低模
轮廓和拓扑稳定性，Multires reshape 也能用；代价是轮廓外扩、深凹遮挡、以及法线图里
本就不存在的低频体积没法唯一恢复。

**基面 = 边界受控的 Catmull-Clark 极限曲面(v6.1/6.3)**。法线贴图只携带高频细节，
低模的粗曲率要靠光滑细分补上(线性细分会把低模折面原样留在高模上)。但 CC 默认会把
开放边界/折痕链平滑成 B 样条曲线——卡片边缘被软化、彼此贴合的边被撕开缝。所以对
**所有 UV 岛边界**(开放边、跨岛边、UV 接缝边)施加 crease=1，并对岛界顶点加
vertex crease=1：折痕链逐级只插线性中点、原顶点钉死，边界折线被精确锁在低模原位
(相当于 EdgeCrease 的严格版)，内部收敛到 C2 极限曲面。折痕写在求值副本上，并与
用户已有折痕取 max，原网格不动。

联合模式只给真实开放/非流形边加上述边界折痕；普通 UV 缝两侧共享连续的
Catmull-Clark 曲面。传统模式仍按全部 UV 岛界锁定，以保持历史结果。

**从切线空间法线到高度场（数学核心，不需要烘焙）**：

```math
\begin{aligned}
\mathbf g
&=
\mathbf n_0
-
\frac{\mathbf n_1}{\mathbf n_1\!\cdot\!\mathbf n_0},
&
\lVert\mathbf g\rVert_2
&=
\tan\theta,\\
q_u
=
\frac{\partial h}{\partial u}
&=
\mathbf g\!\cdot\!\frac{\partial\mathbf P}{\partial u},
&
q_v
=
\frac{\partial h}{\partial v}
&=
\mathbf g\!\cdot\!\frac{\partial\mathbf P}{\partial v}.
\end{aligned}
```

这里 $`\mathbf n_0`$ 是基面法线，$`\mathbf n_1`$ 是材质法线链算出的扰动法线。
得到梯度观测 $`\mathbf q=(q_u,q_v)^\mathsf T`$ 后，以镜像 Neumann 边界做最小二乘
泊松积分：

```math
h^\star
=
\mathrm{arg\,min}_{\mathrm{mean}(h)=0}
\left\lVert\nabla h-\mathbf q\right\rVert_2^2 .
```

FFT 求解的计算复杂度为 $`\mathcal O(N\log N)`$。

$`\mathbf T`$(切线)、$`\mathbf B=s(\mathbf N\times\mathbf T)`$(副切线)、
$`\mathbf N`$(法线)、$`\partial\mathbf P/\partial u,\partial\mathbf P/\partial v`$
(表面对 UV 的解析偏导)
全部来自 **mikktspace 切线帧**(`calc_tangents`，与渲染器同源)加上逐三角形解析几何，
在 UV 网格上向量化光栅化。这样天然带上了镜像 UV 岛的手性(负绕向翻转)、逐岛任意旋转的
切线朝向、逐岛不同的 texel 世界密度。v1 失败的根源就在这里：它直接拿贴图梯度当高度场
全局积分，假设"UV 轴 = 切线轴"，在真实资产上不成立(实测一个发型：406 个 UV 岛 /
144 个镜像岛)。

**镜像 Neumann 积分(v6)**。旧的周期 FFT 假设高度场在图集边界环绕连续，但实际图集
是非周期的，岛之间会隔着边界互相泄漏低频——之前靠高通滤波压，既治标又会削掉真实起伏。
v6 把梯度按对称性以半样本镜像到 $`2H\times2W`$（$`g_x`$ 沿 $`x`$ 反对称、沿 $`y`$ 对称，
$`g_y`$ 相反），再做周期
Frankot-Chellappa。对称数据的最小二乘解自动继承偶对称，取原象限就是 Neumann 边界的
精确解：非周期斜坡能精确还原，没有 wrap-around，高通滤波那套也就去掉了。

**为什么切线帧不能写进共享网格（锯齿的来源）**。发型类资产里，正/背面卡片、镜像复用
UV 往往共用同一批 texel。如果把切线帧光栅化到一张共享网格上，每个 texel 只能存一个面
的属性——正/背面的高度函数互为相反数，最后按三角形光栅化顺序拼成马赛克，积分出来就是
逐三角形的 $`\pm h`$ 锯齿，靠模糊是救不回来的。渲染器不会遇到这个问题，因为每个面永远用自己
的插值属性求值，贴图才是唯一共享的东西。所以这里：

- 切线帧标量只由**正 UV 绕向**的面贡献，逐 texel **取平均**(孤儿镜像岛用负绕向补洞)，
  不做覆盖式光栅化；
- 位移方向不进任何共享网格，由低模自身的插值场求值(见下)。

**渲染级光滑的几何化**(每一层对应渲染 shader 里真实存在的一步)：

| 渲染里做什么 | 这里怎么几何化 |
| --- | --- |
| 平滑法线暗示的粗曲率(光照里的"圆") | 岛界折痕锁定的 **Catmull-Clark 极限曲面**(全局迭代平均，$`C^2`$，逐面不各自独立处理)，边界折线钉死原位 |
| 逐像素连续的法线方向 | 位移方向 = **极限曲面自身的光滑法线场**(极限采样网格的平滑顶点法线，按 $`\mathcal O(\ell^2)`$ 收敛，$`\ell`$ 为顶点间距)。平坦低模的 Phong 插值场在每条基面边上有 $`C^0`$ 折痕，$`h\ne0`$ 处会把线框浮雕进曲面，已弃用 |
| 纹理逐像素连续采样 | 高度场用三次 B 样条($`C^2`$)采样；双线性($`C^0`$)在 texel 边界导数跳变，是"素模视图颗粒感"的来源 |
| — (采样定理约束) | **级别匹配重建滤波** $`\sigma=1.5\,\Delta_{\mathrm{texel}}/\ell`$，其中 $`\Delta_{\mathrm{texel}}`$ 是一个 texel 对应的曲面尺度，$`\ell`$ 是顶点间距。线性网格要呈现平滑曲面，内容波长需 $`\lambda_{\mathrm{detail}}\gtrsim6\ell`$(0.6 系数会把每级钉在约 3.75 采样/波长，恒为折面感且各级观感相同) |
| — (源数据现状) | **源噪声地板**(默认 1px，分辨率无关)：8bit 量化/BC 压缩块的坡度噪声经积分放大成固定尺度凹凸，用恒定 $`\sigma`$ 压掉，避免贴图噪声被当成几何重建出来 |

**曾走过的弯路（基面方案史）**：

- **v5 的 Phong Tessellation**(逐三角形 PN 鼓起)：逐面独立方案只保证 C0，真实资产
  平滑法线场的逐面偏差被各自鼓成密集皱纹，弃用。
- **v5.3 的裸 CC**：边界被平滑软化，靠"SIMPLE 对照细分 + 环形混合"事后拉回，属于
  打补丁，而且输出随细分方式漂移。
- **v6.0 的纯 SIMPLE**：边界精确，但低模折面原样留在高模上(法线图只有高频，补不了
  粗曲率)。
- **v6.1**：CC 极限曲面提供曲率，岛界折痕在细分算子内部锁死边界，两个目标在同一个
  细分算子里同时成立，不需要事后校正。
- **v6.2** 补齐位移的场化：方向从平坦 Phong 插值换成极限曲面法线场(消掉基面边折痕的
  浮雕)；重建滤波从 0.6 提到 1.5×顶点距(消掉各级恒定的近 Nyquist 折面感)；加了分辨率
  无关的源噪声地板(避免压缩/量化噪声被积分成几何凹凸)。

**边界处理（与细分级别无关）**。分两层。几何层：岛界折痕把基面边界折线精确锁在低模
原位(见上，在细分方案内部成立，不需要事后校正)。位移层：高度场在 UV 域沿开放边的
距离场做 smoothstep 衰减归零(半径按贴图像素计)，边界顶点另有硬锁零兜底。两层合起来，
彼此贴合的卡片边在高模上仍然贴合，没有缝隙。衰减场定义在低模 UV 域，与细分级别无关；
旧方案是在细分网格拓扑上做图拉普拉斯平滑，半径随级别漂移，已弃用。

**传统后端的逐岛去趋势(平面拟合) + 岛间最小二乘缝合**。全局积分会给每个 UV 岛留下
任意的常量偏移/线性斜坡。用基面拓扑映射(细分面按基面连续分块，不怕 UV 重叠)把它们
精确归岛后消除，长发/部件分段处就不会有高度台阶。

**材质法线链免烘焙求值**。游戏资产常见的通道重建网络(TexImage/Separate/Combine/
Math/VectorMath/NormalMap 等)由一个小型 numpy 节点求值器直接执行；遇到不支持的节点
或网格(非三角四边面等)自动整体回退 Cycles EMIT 烘焙(见下)。

### 保留的回退路径： Cycles EMIT 烘焙

直算前端要求材质节点在求值器支持范围内。遇到不支持的节点时，整个前端回退到物体空间
EMIT 烘焙(注意 Blender 5.x 的 NORMAL 烘焙通道不含材质法线扰动，实测逐位相同，只能用
EMIT 发射色编码)，同一套梯度/积分/岛处理代数继续走下去——只是数据来源换成三张烘焙图
(扰动法线/基准法线/表面位置)，三张图都烘自低模，不破坏上面的假设。烘焙期间临时切
Cycles(CPU)、隐藏其它物体渲染、插入烘焙目标节点，结束后全部还原；链接库材质无法插
烘焙节点，请先 Make Local。

### 性能

- **Multires 建层只是为了数据结构**(reshape 会完整覆写位移层)，并且延后到求解成功后
  才在隐藏态跑 `multires_subdivide`。细分基面统一走 **Subsurf 折痕 CC 极限求值副本**
  (拓扑/顶点序与 multires 求值逐位一致，实测)，不受 Mesh 里已有位移数据影响。后台求解
  取消或失败时，已有模型不会被删层或重建。
- **重建快路径**：层数已匹配时跳过删层重细分，前端/岛处理全缓存命中。联合解按完整
  几何/拓扑/UV/梯度/参数内容摘要缓存，`disp_scale` 不进求解，所以调倍数只重写位移。
  Rebecca 上身实测冷启动 92.1s，同一解调倍数约 12–14s。
- **联合约束精确压缩**：同一非接缝内部边两侧完全相同的观测会合并并累加权重；UV 缝、
  非流形边或不同目标仍保留双约束。Rebecca 上身从 4,039,296 条 loop 观测压到
  2,037,008 条，不改变最小二乘目标。
- **PCG 内层按连续索引布局**：pinned 端点映射到固定零哑元，避免每次迭代对数百万条边
  重复布尔复制。纯 NumPy 求解，不依赖 SciPy/Numba。7 个真实样本冷启动总时长从 601.5s
  降到 362.3s(降 39.8%)，旧/新截图所有像素差 $`\le1/255`$。
- **交互式后台求解**：bpy 准备、Multires 和 reshape 留在主线程；只把已脱离 Blender
  数据的 NumPy PCG 放进工作线程，并在应用前重新核对完整缓存键。模型、贴图或联合参数
  中途改变时，旧解拒绝写回；`Esc` 可取消。
- **联合模式目前仍用时间换接缝一致性**：百万面样本的 Multires 建层/reshape 本身就要
  40 秒以上，这是当前剩下的主要 UI 阻塞(不是 PCG)。日志会输出约束数、PCG 总迭代、
  残差、降权比例与分阶段耗时。完整的 7 样本性能和视觉回归见
  [`docs/PERFORMANCE_VALIDATION.md`](docs/PERFORMANCE_VALIDATION.md)。
- 每次 `bpy.ops` 调用都会触发整场景深度图刷新，重型角色场景里每个算子白算十几秒。
  构建期间把无关物体临时摘出视图层，结束后还原。
- 全程 numpy 向量化(光栅化按三角形 bbox 尺寸分桶批处理)，没有逐顶点 Python 循环。
- 镜像积分在 4K 工作分辨率下瞬时内存约 1.5GB(numpy FFT 固定 complex128)。

## 选项

| 选项 | 说明 |
| --- | --- |
| 来源 | 自动(材质优先)/ 材质(求值现有材质法线输出)/ 贴图(临时节点链) |
| 重建求解器 | UV Poisson（传统、默认）/ 位置 + 法线联合优化（实验） |
| 高度倍数 | 1.0 = 积分出的物理高度(物体空间单位)；平贴=0；负值反向 |
| 位置保持 | 联合模式的低模位置先验权重；越大越贴近基面，越小越服从法线坡度 |
| 鲁棒迭代 | 联合模式 Huber IRLS 次数；降低互相冲突或异常法线观测的影响；0=普通最小二乘 |
| 边缘衰减 (px) | 高度场向开放边界的 smoothstep 距离衰减半径(贴图像素)；边界顶点始终硬锁零位移；0=只硬锁边 |
| 细节平滑 (px) | 高度场的分辨率无关噪声地板：8bit/BC 压缩坡度噪声经积分成固定尺度凹凸，恒定 $`\sigma`$ 压掉；0=关 |
| 平整死区 (LSB) | 法线 XY 低于该 8bit 台阶数视为纯平，防止量化噪声被积分放大成斑点 |
| 坡度上限 | 坡度($`\tan\theta`$)限幅，压制噪声/压缩伪影导致的孤立尖刺 |
| 自动级别 / 四边形预算 | 级别自动匹配工作分辨率(源贴图原生) × UV 占用率，预算兜底内存 |
| 强制烘焙路径 | 跳过直算前端，强制走 Cycles EMIT 烘焙(兼容任意节点网络) |

## 注意

- 构建期间会**临时**把无关物体摘出视图层求值——结束后全部还原，不留痕迹。
- 直算前端要求网格为三角/四边形(`calc_tangents` 限制)，含五边以上面自动回退烘焙。
- 贴图模式会把文件图色彩空间自动置为 Non-Color(生成型图像跳过，防清像素)。
- 物体上已有**非本工具创建**且带层级的 Multires 时会拒绝执行(防止细节丢失)。

## 开发

`core.py` 为纯 numpy 数学内核，不依赖 bpy：

