# v6.4 联合优化性能与回归验证

本页记录 `feature/joint-position-normal-optimization` 相对上游
`aa37358`（v6.2）的实现边界和测试结果。数据采集于 2026-07-24，
使用 Blender 5.2.0 LTS 与其内置 NumPy 2.3.4；求解器不依赖
SciPy 或 Numba。

## 改动范围

- 在真实细分拓扑上加入位置与法线联合优化，以标量法向位移为未知量；
- 用 Huber IRLS 处理互相冲突的 UV 缝观测、压缩噪声和局部异常值；
- 按 Blender `loop.edge_index` 线性合并完全相同的非接缝内部边观测，
  UV 缝、非流形边和目标不一致的观测仍分别保留；
- PCG 把固定端点映射到零哑元，避免每轮迭代复制百万级边数组；
- 按几何、拓扑、UV、crease、滤波后梯度和求解参数的完整内容摘要缓存
  未缩放联合解，高度倍数不进入缓存键；
- 交互式构建只把脱离 Blender 数据的 NumPy 求解放入工作线程，提供
  进度与 `Esc` 取消；所有 `bpy`、Multires 和 reshape 操作仍在主线程；
- Multires 创建或重建延后到求解成功后，取消、失败或缓存键陈旧均不会
  预先改写模型。

- UV 缝双侧观测不会被错误合并；
- 内容摘要对数组副本稳定，并能识别几何、UV、梯度、形状和类型变化；
- 求解取消与进度完成预算均有回归覆盖。

Blender 5.2.0 LTS 集成验证还覆盖：

- deferred prepare/finalize，确认求解前没有创建 Multires；
- 缓存陈旧保护；
- 真实 GUI modal 完成、进度和 `Esc` 取消；
- 7 个真实样本的固定相机、光照和材质截图矩阵。

## 真实样本冷启动

下表为同一批模型、同一参数和同一机器上的优化前后墙钟时间。每次均为冷启动；
数值是端到端总时间，不只统计 PCG。

| 样本 | 优化前 | 优化后 | 降低 |
| --- | ---: | ---: | ---: |
| Strinova S102 cloth | 62.2s | 36.9s | 40.6% |
| Strinova S105 body | 37.3s | 24.0s | 35.6% |
| Strinova S201 body | 90.6s | 53.1s | 41.5% |
| Strinova S201 hair | 17.2s | 15.7s | 8.6% |
| WuWa Rebecca upper | 157.8s | 92.1s | 41.7% |
| WuWa Rebecca lower | 76.3s | 46.4s | 39.2% |
| WuWa Luokeke upper | 160.1s | 94.1s | 41.2% |
| **合计** | **601.5s** | **362.3s** | **39.8%** |

Rebecca upper 的 4,039,296 条 loop 观测压缩为 2,037,008 条返回约束；
去除固定端点后，求解器实际使用 2,002,288 条。单独 PCG 从约 103 秒
降至 35–40 秒。

同一联合解只改变 `disp_scale` 时，第二次构建约 12–14 秒，PCG 和约束组装
调用次数均保持为 1。位移比例回归的 p95 为 `0.4999972396`
（高度倍数 1.0 改为 0.5）。

## 交互阻塞边界

Rebecca upper 的交互分段如下：

| 阶段 | 线程 | 时间 |
| --- | --- | ---: |
| 数据准备 | Blender 主线程 | 13.93s |
| PCG 求解 | 后台工作线程 | 35.65s |
| Multires 建层与写回 | Blender 主线程 | 49.55s |
| 总墙钟 | — | 99.46s |

因此接近两分钟的连续冻结已被拆开，PCG 期间 Blender 可继续响应和取消。
百万面首次生成仍会在最终 Multires 建层与 reshape 阶段阻塞约 50 秒；
这是当前剩余的主要瓶颈。

## 数值与视觉回归

- 优化前后几何的 p50、p95、p99 和最大位移逐值一致；
- 2/7 组优化前后截图逐像素完全相同；
- 其余截图只出现极少量 `1/255` 的 RGB 差异；
- 所有样本均没有像素差超过 `1/255`。

真实样本、原始截图和生成的 `.blend` 不随仓库提交，避免重新分发第三方资产。
自动化算法测试保留在 `tests/`，真实资产结果只作为本地验收证据。

## 当前限制与后续方向

当前不建议直接把 coarse-to-fine 或 Poisson/Joint 混合求解改为默认路径：

- 现有优化未改变目标函数，已经把 7 样本端到端总时间降低 39.8%；
- coarse-to-fine 需要可靠的 Catmull-Clark 层间 prolongation，并会改变
  IRLS 权重演化，需要独立的误差和接缝回归；
- 即使 PCG 时间归零，Rebecca upper 仍有约 43–50 秒用于 Multires
  建层和 reshape。

下一步更值得单独验证的是“快速独立高模 Mesh 输出”，或“低级别可交互预览，
确认后再提交最终 Multires”的双阶段路径。现有 Multires 输出应继续保留为
可编辑、多级细节的兼容模式。
